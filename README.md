# C-Library-Management-System

基于 C 语言和顺序表（SeqList）实现的控制台图书管理系统。

本项目作为大二上学期《数据结构》课程的实战练习，从零手搓底层数据结构，并逐步完成了健壮性加固与功能扩展，当前版本已正式封盘。

## 核心功能
- **交互式菜单**：使用 `while` + `switch` 实现的死循环菜单。
- **图书录入**：支持在书库末尾追加新书，包含容量校验与长度限制。
- **图书删除**：按序号删除指定图书，并自动挪动后续数据。
- **图书查找**：按书名进行精确查找，支持错误提示。
- **图书修改**：按序号覆盖修改原有图书信息。
- **遍历打印**：格式化输出当前库中所有图书的详细信息。
- **数据持久化**：程序启动时自动从 `book.txt` 读取数据，退出时覆盖保存。

## 技术栈与工程特性
- **语言**：C 语言（纯标准库，无第三方依赖）
- **底层结构**：基于定长数组实现的顺序表（SeqList）。
- **防御性编程**：
  - 针对交互输入和文件读取均加入了严格的字符串长度限制（`%49s` / `%29s`），防止缓冲区溢出。
  - 针对所有 `scanf` 输入进行了异常拦截，防止输入字母导致死循环。
  - 完善的指针边界校验，防止数组越界。
  - 对 `malloc` 进行了非空校验。
- **内存管理**：程序退出前使用 `free` 安全释放堆内存，无泄漏。

## 编译与运行
1. 打开终端（命令行），进入项目目录。
2. 编译代码：`gcc seqlist_library_system.c -o library`
3. 运行程序：
   - Windows：`.\library.exe`
   - Mac/Linux：`./library`

## 已知限制 (Known Limitations)
- **空格限制**：字段以空格分隔，无法存储包含空格的书名或作者。
- **容量上限**：单库上限为 100 本，超出后录入失败。
- **保存时机**：数据仅在正常退出（输入 0）时保存，强制结束进程（如直接关闭窗口）会丢失本次修改。
