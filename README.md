# C-Library-Management-System

基于 C 语言和顺序表（SeqList）实现的控制台图书管理系统。

本项目作为大二上学期《数据结构》课程的实战练习，从零手搓底层数据结构，并逐步完成了工程化重构与健壮性升级，当前版本已正式封盘。

## 核心功能
- **交互式菜单**：使用 `while` + `switch` 实现的死循环菜单，支持连续操作。
- **图书录入**：支持在书库末尾追加新书，包含容量校验与长度限制（防溢出）。
- **图书删除**：按序号删除指定图书，并自动挪动后续数据填补空缺。
- **图书查找**：按书名进行精确查找，支持错误提示。
- **图书修改**：按序号覆盖修改原有图书信息。
- **遍历打印**：格式化输出当前库中所有图书的详细信息（序号、书名、作者、价格）。
- **数据持久化**：程序启动时自动从 `book.txt` 读取历史数据，退出时自动覆盖保存当前状态。

## 技术栈与工程特性
- **语言**：C 语言（纯标准库实现，无第三方依赖）
- **底层结构**：基于定长数组实现的顺序表（SeqList）
- **防御性编程**：
  - 针对所有 `scanf` 输入进行了严格拦截（防止输入字母导致死循环或数据污染）。
  - 对 `malloc` 进行了非空校验。
  - 对字符串输入（书名、作者）使用 `%49s` 和 `%29s` 限制了最大读取长度，彻底杜绝缓冲区溢出（Buffer Overflow）风险。
  - 完善的指针边界校验（防止数组越界与非法位置访问）。
- **内存管理**：程序退出前使用 `free` 安全释放堆内存，无内存泄漏。

## 编译与运行
本项目为 C 语言命令行程序，使用 GCC 编译器进行编译。

1. 打开终端（命令行），进入项目所在目录。
2. 输入以下命令编译代码：
   `gcc seqlist_library_system.c -o library`
3. 运行编译出的可执行文件：
   - Windows 系统：`.\library.exe`
   - Mac/Linux 系统：`./library`
4. 首次运行时会自动生成 `book.txt` 用于保存数据。
